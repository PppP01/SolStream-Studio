## 8. For AI Coding Assistants, Security Auditors & Forkers

### Strict Architectural Invariants for AI Assistants / PR Contributors
1. **NEVER** promote `SolStreamService` to `FOREGROUND_SERVICE_TYPE_MEDIA_PROJECTION` before `Activity.RESULT_OK` from `MediaProjectionManager.createScreenCaptureIntent()`, **ALWAYS** call `startForeground()` before any early return in `startLiveBroadcast()`, **ALWAYS** await `activeTeardownLatch` off the main thread with an explicit timeout abort + cancellation check in `continueStartLiveBroadcast()`, **ALWAYS** open `DiagnosticsLogger.startNewSession(..., saveInitialCheckpoint = false)` *before* pipeline init so `[GL_INIT]`/`[AUDIO_ENC]` logs are preserved, and **ALWAYS** call `DiagnosticsLogger.lockFinalMicStatusBeforeStop()` + `videoPipeline.prepareForImmediateStop()` synchronously before async teardown.
2. **NEVER** catch transient video or AAC `MediaCodec.CodecException` *outside* the `while (isRunning)` drain loop—always retry up to the bounded limit inside the loop and escalate unrecoverable failures cleanly to `onFatalPipelineError` / `onFatalAudioError` (which stops the broadcast so viewers never receive frozen or silent streams). Always isolate `RtmpClient.sendVideo()` / `sendAudio()` in `try/catch` so transient socket disconnect races never terminate hardware encoder drain threads.
3. **NEVER** flip `rtmpConnected = true` or auxiliary `connected = true` before pushing cached `SPS/PPS/VPS` headers (`setVideoInfo`), and **ALWAYS** auto-reconnect dropped auxiliary targets on both `onConnectionFailed` and `onDisconnect` unless `authRejected` is set.
4. **NEVER** bypass `KeystoreVault.enforcePlatformLimits()` on UI changes, profile imports, or encoder startup, **NEVER** lock or cap YouTube/Custom RTMP resolutions, bitrates, or `SolShorts™` toggles, and **NEVER** enable `maxBFrames > 0` while `RootEncoder 2.8.x`'s RTMP packetizer writes `CTS = 0`.
5. **NEVER** render a `SolShorts™` Minimap Loupe when `SolVideoPipeline.isMinimapLoupeSuppressedByShield()` returns `true` (so stream-sniper privacy blur is never bypassed), **ALWAYS** route `9:16` Shorts header/Loupe placement through `SolHudAndQrRenderer.computeShortsTopLayout()` (capped at `<= +0.700 NDC` to stay clear of YouTube's `15%` mobile header), and **ALWAYS** pass incoming `onCapturedContentResize` dimensions through `scaleCaptureForShortsCooler(..., outShortSidePx)` so `<=1080p` vertical saves bandwidth while `>1080p` vertical never downscales.
6. **NEVER** mutate `Biquad64` coefficients from the UI thread—publish an immutable `DspConfigSnapshot` atomically and apply filter updates strictly on the audio thread at `10 ms` frame boundaries; keep noise-floor updates frozen during active speech and mute; preserve the `1.5s` post-call BT SCO settle window and `onStop()` offline 10s mic-test stop hook in `SolDualAudioEngine`.
7. **NEVER** restart a microphone solely for brief digital silence when Android reports `isClientSilenced == false`—keep `SolDualAudioEngine.shouldTriggerMicRecovery()` gated on read errors, OS-silenced status, and the `15s` cooldown, and never release shared audio resources until `AudioWorkerBarrier` confirms both workers have exited.
8. **NEVER** call `glReadPixels()` directly on a `MediaCodec` `InputSurface` (always render into a temporary offscreen RGBA8 FBO *after* `eglSwapBuffers()`, detach `GL_COLOR_ATTACHMENT0`, unbind `GL_TEXTURE_2D`, restore `glBindFramebuffer(0)` + `glViewport`, delete FBO/texture, and call `glFlush()` in `finally`), and **NEVER** allocate new `Bitmap` objects per frame inside the OpenGL render loop (`SolHUD™` must reuse its scratch bitmap via `glTexSubImage2D`).
9. **NEVER** enable `setCheckServerAlive(true)` on Pedro's `RtmpClient`, **NEVER** open test `MediaCodec` encoders while `isBroadcastLive || isBroadcastStartingOrLive`, **NEVER** poll `PowerManager.getThermalHeadroom()` faster than once every `10.5s`, **NEVER** classify USB or Wireless `NOT_CHARGING` as `Bypass Charging (USB-PD)`, and **NEVER** resize `VirtualDisplay` while `!capturedContentVisible` or to portrait dimensions during a `16:9` stream.
10. **NEVER** re-introduce `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`, `CAMERA`, `READ/WRITE_EXTERNAL_STORAGE`, `READ_MEDIA_IMAGES`, `ACCESS_FINE_LOCATION`, `SYSTEM_ALERT_WINDOW` (prior to Phase 2 Offline Recorder), `AudioManager.setCommunicationDevice()`, `-ffast-math` in `CMakeLists.txt`, or CPU software video encoders (`c2.android.av1.encoder`).
